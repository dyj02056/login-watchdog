01 · 요청의 이동 경로

로그인 시도 한 건이 파일 사이를 어떻게 지나가는가

평소엔 위쪽 한 줄(정상 경로)만 돌지만, 같은 IP가 60초 안에 5회를 넘기는 순간 아래쪽 경로(SOAR 대응)가 열립니다. 점선은 해제가 다시 로그인 라우트로 돌아오는 경로입니다. 같은 계정이 여러 IP에 걸쳐 8회를 넘기면 계정 단위 잠금이, 반복되면 영구 잠금(04절)이 이어집니다.
