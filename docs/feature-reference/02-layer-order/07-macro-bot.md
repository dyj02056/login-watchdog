# 7. API 엔드포인트 매크로/봇 탐지

<aside>
🎯 **한 줄 요약**
짧은 시간에 **서로 다른 API 주소를 기계적으로 훑고 다니는** 스크립트(매크로·봇)를 잡아냅니다. 같은 주소 하나만 반복하는 것은 6단원이, **여러 주소를 옮겨 다니는 것**은 이 단원이 맡습니다.
</aside>

> 🗺️ **클릭해서 코드를 볼 수 있는 흐름도**: [07-macro-bot.html](07-macro-bot.html)
> 📚 **계층**: Layer 2. 탐지

---

## 🏢 비유로 먼저 이해하기

| 현실 | 이 프로젝트 |
|---|---|
| 사람은 문 한두 개를 열어본다 | 사람이 화면을 눌러 API 몇 개를 호출 |
| 도둑은 복도의 **모든 문**을 차례로 당겨본다 | 스크립트가 **여러 API**를 기계적으로 훑음 |
| "1분에 서로 다른 문 6개" 이상이면 의심 | 60초 안에 서로 다른 `/api/*` 경로 **5개 초과** |

<aside>
💡 **왜 따로 필요한가요?**
6단원의 "반복 페이지 접근"은 **GET 요청 + 같은 경로 하나의 반복**만 봅니다. 스크립트가 POST를 섞거나 경로를 계속 바꾸면 그 감시를 피할 수 있습니다. 그래서 **메서드를 가리지 않고(POST 포함) "서로 다른 경로의 개수"** 를 세는 탐지를 따로 둡니다.
</aside>

---

## 🔄 동작 순서

모든 `/api/*` 요청이 들어올 때마다(화면 함수가 실행되기 직전) 훅이 호출됩니다.

| 순서 | 동작 | 쉬운 설명 |
|:-:|---|---|
| ① | 관찰 대상 거르기 | `/api/`로 시작하지 않거나, 대시보드·게시판의 **자동 폴링 API는 제외** |
| ② | 호출 기록 | IP·경로·메서드(GET/POST…)를 한 줄 저장 |
| ③ | **서로 다른 경로가 몇 개?** | 최근 60초 안에 호출한 경로의 종류 수를 세어 5개 초과 + **정확히 6번째 경로**일 때만 "수상" |
| ④ | 알림 + 기록 | Slack 알림 + `API_MACRO_PATTERN`(MEDIUM) 기록. **잠그지는 않음** |
| ⑤ | 코앞이면 AI 조기 경보 | 기준 직전이면 LLM에게 조기 경보 여부를 물음 (11단원) |

<aside>
🧮 **"서로 다른 경로의 개수"는 어떻게 셀까요?**
이 IP의 최근 60초 호출 경로를 모두 가져와서 **중복을 없앤(set)** 뒤 개수를 셉니다. 같은 경로를 100번 불러도 1개로 셉니다. 5단원에서 "서로 다른 아이디 개수"로 Brute Force와 Password Spraying을 구분하던 것과 같은 발상입니다.
</aside>

## 📍 코드는 어디에 있나요?

| 하는 일 | 파일 | 함수 |
|---|---|---|
| 요청 훅 (관찰 지휘) | `helpers/hooks.py` | `track_api_access()` |
| 매크로/봇 판정 | `security/detector.py` | `is_macro_pattern_suspicious()` |
| API 호출 기록 | `db/api_access_log.py` | `log_api_access()` |
| 서로 다른 경로 개수 세기 | `db/api_access_log.py` | `count_recent_distinct_api_paths()` |
| 알림 + 기록 | `security/soar/observe.py` | `notify_macro_pattern()` |
| Slack 알림 | `notify/alert.py` | `send_macro_pattern_alert()` |

## 🧪 예시로 보기

스크립트가 60초 안에 `/api/status`, `/api/unlock`, `/api/users/delete`, `/api/board/posts/delete`, `/api/settings/signup`, `/api/admin-users/create` **6개의 서로 다른 API**를 호출하면
→ **6번째 경로 호출 순간** MEDIUM(`API_MACRO_PATTERN`) 알림 1회.

## 🖥️ 직접 해보기

- [ ] 관리자로 로그인한 세션 쿠키를 유지한 채, 6개 이상의 서로 다른 `/api/*` 경로를 60초 안에 빠르게 호출하는 스크립트를 실행한다
- [ ] 콘솔(또는 Slack)에 MEDIUM 알림이 뜨는지 확인한다

> 대시보드 자체의 자동 폴링(`/api/status`)은 관찰 대상에서 제외되므로 횟수에 잡히지 않습니다.

## 📖 용어 사전

<details>
<summary><b>매크로(Macro)</b></summary>

사람이 하던 반복 작업을 자동화하려고 미리 짜 둔 스크립트·도구입니다.
</details>

<details>
<summary><b>폴링 API 제외</b></summary>

대시보드와 게시판은 5초마다 같은 API를 자동으로 호출합니다. 이것까지 세면 정상 사용자가 매번 "수상"으로 잡히므로, 해당 엔드포인트는 처음부터 관찰 대상에서 뺍니다.
</details>

## ⚠️ 알아둘 한계

- "서로 다른 경로 개수"만 보므로, **같은 API 하나만 반복 호출**하는 패턴은 여기서 안 걸립니다. 그 경우는 요청량 자체로 막는 15단원의 HTTP 플러딩 방어가 맡습니다.
