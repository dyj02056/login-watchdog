# 무료 VPN으로 "다른 나라에서 접속한 것처럼" IP 잠금·GeoIP 데모하기

> 이 문서는 개발 지식이 없어도 따라할 수 있도록, ProtonVPN(무료)을 이용해 login-watchdog의
> "브루트포스 IP 잠금"과 "GeoIP 국가·도시 표시" 기능을 실제로 시연했던 과정을 그대로 기록한
> 것입니다. `docs/beginner-guide/`의 문서들이 "어떻게 만들었는가"를 다룬다면, 이 문서는
> "만들어진 기능을 어떻게 보여주는가(데모 절차)"를 다룹니다.

---

## 한눈에 요약

- **목적**: 배포된 사이트(Vercel)에 접속할 때, 실제로 "다른 나라 IP"에서 온 것처럼 보이게 만들어서
  IP 기반 로그인 잠금 기능과 위치(GeoIP) 표시 기능이 잘 동작하는지 눈으로 보여준다.
- **왜 헤더 조작이 아니라 VPN을 쓰는가**: `bruteforce_sim.py`의 `--ip` 옵션은 `X-Forwarded-For`
  헤더에 가짜 IP를 실어 보내는 방식인데, 배포 사이트는 안전을 위해 이 헤더를 신뢰하지 않도록
  설정(`TRUST_FORWARDED_FOR=false`)되어 있어 배포 사이트에서는 효과가 없다. VPN은 헤더를
  조작하는 게 아니라 **실제 접속 경로 자체**를 바꾸므로, 서버가 보는 "진짜 접속 IP"가
  정말로 바뀐다. 그래서 배포 사이트에서도 정상적으로 통한다.
- **사용 도구**: ProtonVPN 무료 버전 (설치·가입 무료, 이메일만 있으면 됨)
- **결과**: 실제로 네덜란드 IP(`149.34.244.170`)로 접속해 6회 로그인 실패 → 정상적으로
  IP가 잠기고, 관리자 대시보드에 `The Netherlands · Amsterdam`까지 정확히 표시되는 것을 확인함.

## 진행 절차

### 1단계 — ProtonVPN 설치 및 가입

1. ProtonVPN 공식 홈페이지에서 Windows용 클라이언트를 내려받아 설치한다.
2. 이메일 주소로 무료 계정을 가입한다. (계정 생성은 반드시 본인이 직접 진행)
3. 앱을 실행하고 로그인한다.

### 2단계 — 무료 서버로 연결

1. 앱 중앙의 **"연결"** 버튼을 누르면 무료로 이용 가능한 서버(미국·네덜란드·일본 등) 중
   가장 빠른 곳에 자동으로 연결된다.
2. 연결되면 화면 좌측 상단의 상태가 **"보호되지 않음" → "보호됨"**으로 바뀐다.
   - "보호되지 않음"이 보인다고 문제가 생긴 것은 아니고, 단순히 아직 연결 전이라는 뜻이다.
3. 다른 나라로 바꾸고 싶으면 **"서버 변경"** 버튼을 눌러 무료 서버 중 하나로 다시 전환하거나,
   좌측 위 검색창에 원하는 국가명을 직접 입력해서 찾는다.
   - 무료 계정은 국가 목록 전체(149개국) 중 **번개(⚡) 아이콘이 붙은 소수의 국가만** 이용
     가능하다. 번개 표시가 없는 국가를 클릭하면 "Plus 요금제 필요" 안내가 뜨는데, 이는
     정상적인 유료 전용 안내이므로 무시하고 번개 표시된 국가만 고른다.

### 3단계 — 실제로 IP가 바뀌었는지 확인

1. 브라우저에서 `whatismyipaddress.com` 같은 IP 확인 사이트에 접속한다.
2. 표시되는 국가와 IP 주소가 한국(원래 내 IP)이 아니라 방금 연결한 VPN 서버의 국가로
   바뀌었는지 확인한다.
3. (참고) 이런 사이트는 VPN IP를 "Public Proxy Server"로 표시하며 경고를 띄우기도 하는데,
   국가·도시 정보 자체는 정확하므로 데모 목적으로는 문제없다.

### 4단계 — 브루트포스 시뮬레이션 스크립트 실행

VPN이 연결된 상태를 유지한 채로, 프로젝트 폴더에서 가상환경을 통해 스크립트를 실행한다.
대상 주소는 **지금 작업 중인 브랜치의 Vercel 프리뷰 주소**(운영 주소인
`login-watchdog.vercel.app`이 아님)를 사용한다.

```bash
python scripts/bruteforce_sim.py --host https://<브랜치-프리뷰-주소>.vercel.app --username test1 --i-know-what-im-doing
```

- `--i-know-what-im-doing`: 로컬(127.0.0.1)이 아닌 주소를 대상으로 실행하려면 반드시 필요한
  안전장치용 플래그. 본인이 소유한 배포 사이트이므로 사용해도 안전하다.
- `--ip` 옵션은 넣지 않는다. 배포 사이트에서는 어차피 무시되고, VPN 덕분에 이미 접속 경로
  자체가 바뀐 상태라 필요하지 않다.
- 프리뷰 주소가 Vercel Authentication(접근 보호)으로 막혀 있다면, `.env`의
  `VERCEL_AUTOMATION_BYPASS_SECRET` 값을 스크립트가 자동으로 읽어 우회한다(`--bypass-secret`을
  따로 지정할 필요 없음).
- 정상적으로 실행되면 아래처럼 6번째 시도에서 잠금 문구를 확인했다는 메시지가 출력된다.

```
[*] .../login 에 틀린 비밀번호로 6회 연속 로그인 시도
    시도 1/6 - 상태 코드 200
    ...
    시도 6/6 - 상태 코드 200 - 이미 잠김
[OK] 6번째 시도에서 '잠긴 계정입니다' 문구를 확인했습니다. 잠금 정상 동작.
```

### 5단계 — 관리자 대시보드에서 확인

1. 관리자 계정으로 대시보드에 접속한다(가능하면 VPN을 끄고 본인 실제 IP로 접속 —
   같은 VPN IP로 관리자 로그인까지 하면 관리자 계정 쪽 실패 카운트와 섞일 수 있다).
2. **"현재 잠긴 IP"** 카드에서 방금 사용한 VPN IP가 "실패 6회"로 표시되고, 해제 예정
   시각이 함께 뜨는지 확인한다.
3. 로그인 시도 이력 테이블에서는 IP뿐 아니라 **국가·도시(GeoIP)** 정보까지 함께 표시된다.
   실제 확인된 예시:

   | 시작 | IP | 위치 | 아이디 | 결과 |
   |---|---|---|---|---|
   | 오후 7:30:00 | 149.34.244.170 | The Netherlands · Amsterdam | test1 | 실패 |

### 6단계 — 다른 국가로 반복 (선택)

여러 나라의 기록을 함께 보여주고 싶다면:

1. ProtonVPN에서 연결 해제 후 다른 무료 국가로 재연결한다.
2. 3~5단계를 다시 반복한다.
3. 대시보드에 서로 다른 국가의 기록이 함께 쌓이는 것을 보여주면 데모가 완성된다.

### 7단계 — 정리

데모가 끝나면 테스트로 잠긴 IP를 풀어준다.

```bash
python scripts/unlock_ip.py --all   # 활성 잠금 전부 즉시 해제
```

## 자주 막히는 부분 (트러블슈팅)

- **"보호되지 않음"이 떠요** → 문제 아님. 아직 연결 전이라는 표시일 뿐이며, "연결" 버튼을
  누르면 사라진다.
- **국가 목록에 번개 아이콘이 하나도 안 보여요** → 지금 보고 있는 국가들이 전부 유료(Plus)
  전용이라 그렇다. 목록을 스크롤하며 찾지 말고, 검색창에 원하는 국가명(예: "일본", "미국")을
  직접 입력해서 번개 아이콘이 있는지 확인하는 것이 더 빠르다.
- **어느 URL에 실행해야 할지 헷갈려요** → 지금 작업 중인 브랜치 이름이 들어간 프리뷰 주소
  (`login-watchdog-git-<브랜치명>-*.vercel.app`)를 사용한다. 운영 주소(`login-watchdog.vercel.app`)는
  main 브랜치 기준이라 지금 하려는 데모와 무관하다.
- **VPN마다 접속할 때 IP가 조금씩 달라져요** → 정상이다. 같은 나라·서버라도 요청마다 다른
  출구 노드를 탈 수 있다. 잠금 기능은 그 순간의 접속 IP 기준으로 개별 동작하므로 데모에는
  영향이 없다.
