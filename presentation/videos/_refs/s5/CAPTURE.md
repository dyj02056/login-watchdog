# S5 시연 캡처 안내 (SYN 폭주, NET-01)

이 폴더에는 **최종 영상이 아니라** HyperFrames 애니메이션을 실제와 똑같이 그리기 위한
참고 자료(터미널 텍스트 + 대시보드 스크린샷)를 넣습니다. 동영상은 필요 없고 정지 캡처면 됩니다.

> **방식: 일회용 새 IP** — 고정 상자(.103)를 재사용하면 앞선 차단이 남아 재현이 어긋납니다.
> 그래서 테이크마다 **쓰지 않은 새 IP**로 일회용 컨테이너를 띄웁니다. (netwatch/README.md 7.3 방식)

## 0. 촬영 전 (한 번만)
```bash
docker compose up -d --build
docker compose build attacker-1   # 일회용 컨테이너가 쓰는 lw-attacker:latest 이미지 최신화
```
- 새 IP 방식이라 attacker-3(.103)을 따로 해제할 필요 없습니다.
- **재촬영할 때는 아래 IP 끝자리(.172)를 안 쓴 숫자로 바꾸세요** (측정용 범위 `.150~.199`).
- `Address already in use` 에러가 나면 그 IP가 직전 컨테이너에 남은 것 → **다른 끝자리**로 바꾸면 됩니다.

## 1. 터미널에 입력할 명령 (왼쪽 화면)
공격 IP = `172.28.0.172`.

```powershell
# 컷1 — SYN 폭주
docker run --rm --network lw_edge --ip 172.28.0.172 --cap-add NET_RAW -e TARGET_URL=http://172.28.0.10:8080 lw-attacker:latest synflood --count 3000
```
컷2~5는 명령 없이, 폭주 직후 관제 화면에서 순서대로 캡처합니다 (목표 5초 내, 중앙값 ≈2.7초).
