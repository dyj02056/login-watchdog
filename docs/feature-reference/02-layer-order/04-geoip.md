# 4. IP 위치 조회 (GeoIP)

<aside>
🎯 **한 줄 요약**
"IP 1.2.3.4에서 로그인 시도"라는 숫자 대신 **"베트남 하노이에서 시도"** 처럼 국가·도시로 바꿔 보여줍니다. 평소와 다른 지역에서의 시도를 한눈에 알아채기 위해서입니다.
</aside>

## 🏢 비유로 먼저 이해하기

| 현실 | 이 프로젝트 |
|---|---|
| 우편번호로 지역 알아내기 | IP 주소로 국가·도시 알아내기 |
| 전화번호부(외부 안내 서비스) | 외부 서비스 `ip-api.com` |
| 안내에 한 번 물어본 번호는 수첩에 적어두기 | **캐시** (`ip_locations` 표) |

<aside>
💡 **왜 수첩(캐시)이 필요한가요?**
무료 서비스는 **1분에 45건**까지만 물어볼 수 있습니다. 대시보드가 5초마다 화면을 다시 그리면서 매번 물어보면 금방 한도를 넘깁니다. 그래서 **한 번 물어본 IP는 저장**해 두고 다음부터는 저장된 값을 씁니다.
</aside>

## 🔎 위치가 붙는 순서

| 순서 | 동작 | 쉬운 설명 |
|:-:|---|---|
| 시작 | 로그인 시도 목록을 그린다 | 회원 "내 로그인 기록"과 관리자 대시보드가 각 줄에 위치를 붙이려고 요청 |
| ① | 중복 제거 + 저장된 값 확인 | 같은 IP는 한 번만. 이미 아는 IP는 **쿼리 한 번**으로 한꺼번에 가져옴 |
| ② | 아는 IP는 재사용 | 외부에 묻지 않고 저장된 값 사용 (조회에 **실패했던 IP도** 저장되어 있어 헛수고 방지) |
| ③ | 모르는 IP만 새로 물어보고 저장 | 결과를 저장해 다음에는 묻지 않음 |
| ④ | 사람이 읽을 문장으로 | `South Korea · Seoul` / 실패면 `위치 확인 불가` |

## 🛡️ 외부에 물어볼 때의 안전장치 (SSRF 방지)

외부 주소에 IP를 **그대로 끼워 넣어** 요청하기 때문에, IP 자리에 이상한 문자열이 들어오면 외부 요청이 조작될 수 있습니다.

| 순서 | 동작 |
|:-:|---|
| ① | **진짜 IP 형식인가?** 아니면 외부로 요청 자체를 보내지 않고 "조회 실패"로 처리 |
| ② | 외부 서비스에 국가·지역·도시만 요청 (**5초** 안에 답이 없으면 포기) |
| ③ | 네트워크 문제나 사설 IP(127.0.0.1 등)도 모두 "값 없음"으로 처리 |
| ④ | 성공하면 국가·지역·도시를 돌려줌 |

<aside>
⚠️ **SSRF란?** 서버가 대신 외부에 요청을 보내는 기능을 공격자가 악용해, 의도하지 않은 주소로 요청을 보내게 만드는 공격입니다. 입력이 "진짜 IP"인지 먼저 확인하는 것이 가장 단순한 방어입니다. (15단원에서 전체 목록을 다시 다룹니다.)
</aside>

## 📍 코드는 어디에 있나요?

| 하는 일 | 파일 | 함수 |
|---|---|---|
| 목록에 위치 붙이기 | `helpers/request_utils.py` | `_attach_locations()` |
| 캐시 먼저 → 없으면 외부 조회 | `services/geoip.py` | `get_locations()` |
| 외부 서비스에 실제 요청 | `services/geoip.py` | `_fetch_location()` |
| 화면용 문장 만들기 | `services/geoip.py` | `format_location()` |
| IP 형식 확인 | `services/ip_utils.py` | `lookup_address()` |
| 저장된 위치 읽기·저장 | `db/geoip_cache.py` | `get_cached_ip_locations()`, `save_ip_location()` |

## 🧪 예시로 보기

| 상황 | 화면에 보이는 값 |
|---|---|
| 내 컴퓨터(`127.0.0.1`)에서 접속 | `위치 확인 불가` (사설 주소라 위치가 없음) |
