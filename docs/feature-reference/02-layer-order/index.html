login-watchdog 코드 흐름도

로그인 감시 시스템의 32개 기능이 어떤 파일의 어떤 함수를 거쳐 가는지를 그림으로 보는 안내서입니다.

단원 카드를 열면 흐름도가 나옵니다. 흐름도의 카드(파일·함수 이름)를 누르면 실제 코드가 오른쪽에 열리고, 코드 패널의 너비는 경계선을 끌어서 조절할 수 있습니다.

Layer 1. 기반 기능

사용자가 직접 쓰는 화면 — 감시 대상

1. 인증 (회원가입 / 로그인)
회원가입과 로그인 요청이 어떤 파일의 어떤 함수를 거쳐 가는지 한눈에 보는 코드 흐름도
2. 회원 대시보드
로그인한 회원이 자기 정보를 보고 고치는 화면들이 어떤 함수를 거치는지 보는 코드 흐름도
3. 게시판 · 댓글
글쓰기·수정·삭제·댓글·새 댓글 알림이 어떤 파일의 어떤 함수를 거치는지 보는 코드 흐름도
4. IP 위치 조회 (GeoIP)
IP 주소가 '어느 나라 어느 도시'로 바뀌어 화면에 나오기까지의 코드 흐름도

Layer 2. 탐지

"이거 수상한가?"를 판단만 하는 판사

5. 브루트포스 탐지 + 자동 IP 잠금
로그인 실패가 쌓였을 때 '수상한가?'를 판정하고 IP·계정을 잠그기까지의 코드 흐름도
6. 공격 유형별 탐지 매트릭스
404 반복·미인증 API·반복 접근·도배 같은 '관찰형' 탐지가 어디서 호출되고 무엇을 하는지 보는 코드 흐름도
7. API 엔드포인트 매크로/봇 탐지
서로 다른 /api/* 경로를 기계적으로 훑는 스크립트를 잡아내는 코드 흐름도

Layer 3. 대응

실제로 잠그고·알리고·엮는 집행관·형사

8. 통합 보안 위험등급
서로 다른 이상행위가 CRITICAL / HIGH / MEDIUM 등급과 함께 하나의 표에 모이는 코드 흐름도
9. SIEM 상관분석
흩어진 이벤트들이 '하나의 공격 사건'으로 묶이고 닫히는 과정의 코드 흐름도
10. SOAR 플레이북
심각한 복합 공격에만 한 번 더 강조 알림을 보내는 플레이북과, 집행관(soar) 함수 지도
11. LLM 판단 에이전트
임계값 코앞의 사각지대에서 AI에게 한 번 더 묻고, 관리자가 승인해야 조치가 실행되는 코드 흐름도

Layer 4. 관리

자동 대응을 사람이 보고 되돌리는 최종 판단

12. 관리자 대시보드
자동 대응 위에 '사람의 최종 판단'을 얹는 관리자 화면의 데이터 흐름과 처리 버튼의 코드 흐름도
13. 관리자 RBAC
관리자 요청이 '세션 확인 → 역할별 권한 확인'의 두 단계 문지기를 통과하는 코드 흐름도
14. 임계값 튜닝 리포트
'우리 임계값이 너무 예민한 건 아닐까?'를 데이터로 점검하는 리포트 스크립트의 코드 흐름도

Layer 5. 방어 강화 · 확장

개별 취약점 보강, 영구 잠금, 복구, 이메일 인증, 화면 어댑터 등

15. L7 공격 방어 보강
IP 잠금만으로는 못 막는 공격(클릭재킹·대량 요청·봇·타이밍·SSRF·오픈 리다이렉트)을 메우는 방어들의 코드 흐름도
16. 영구 잠금
5분 임시 잠금이 반복되면 자동 만료 없는 '영구 잠금'으로 올라가고, 사람이 풀 때까지 유지되는 과정의 코드 흐름도
17. 이메일 인증 복구
영구 잠긴 사용자가 본인 이메일로 스스로 잠금을 푸는 과정과, 그 과정을 악용하지 못하게 하는 안전장치의 코드 흐름도
18. 비밀번호 변경 + 다른 기기 로그인 해제
비밀번호를 바꾸면 다른 기기의 로그인이 모두 끊기는 '세션 세대 번호' 방식의 코드 흐름도
19. 배포 환경 DB 연결 안정화
서버리스에서 쉬던 DB 연결이 끊겨 생기던 500 오류를, 연결 한 곳만 고쳐서 막은 코드 흐름도
20. 복구 코드 시도 제한 + 관리자 세션 검증
'비교하기 전에 시도권부터 예약'하는 복구 코드 방어와, 요청마다 DB 계정과 대조하는 관리자 세션 검증의 코드 흐름도
21. 관리자 계정 단위 잠금
IP를 나눠 쓰는 분산 브루트포스로부터 관리자 계정을 지키는 계정 단위 잠금의 코드 흐름도
22. 계정 존재 여부 노출 방지
화면 문구·응답 시간 차이로 '이 아이디가 가입돼 있다'가 새지 않게 막는 장치들의 코드 흐름도
23. 이메일 인증 + 이메일 변경 보호
가입 이메일을 인증하고, 이메일 변경을 '현재 비밀번호 + 새 주소 확인 링크'로 보호하는 코드 흐름도
24. 비밀번호 찾기
비밀번호를 잊은 회원이 '인증된 이메일'로 스스로 재설정하는 과정의 코드 흐름도
25. 복구 요청 한도 + 처리 시간 기록
'항상 같은 시간 뒤에 응답'하는 요청이 서버 함수를 오래 붙잡지 못하게 한도를 걸고, 실제 처리 시간을 기록하는 코드 흐름도
26. 로그 자동 정리 + 일별 요약
매일 새벽 3시, DB 안에서 '요약 → 정리' 순서로 도는 SQL 함수들의 코드 흐름도 (앱 코드와 무관)
27. 보이지 않는 탭은 폴링하지 않음
탭이 안 보이면 멈추고, 돌아오면 즉시 갱신하는 공용 폴링 부품(polling.js)의 코드 흐름도
28. 대시보드 즉시 반응
버튼을 누르는 순간 화면이 먼저 반응하고, 표 하나만 다시 받는 대시보드 속도 개선의 코드 흐름도
29. IPv6 /64 대역 단위 정규화
요청 IP 를 '탐지·잠금 단위'로 바꾸는 한 곳(get_request_ip)과, 그 값이 쓰이는 곳들의 코드 흐름도
30. Next.js 관제 화면과 집계 API
화면은 Next.js 정적 빌드로, 보안 로직은 기존 Flask 라우트 그대로 — 둘을 이어주는 어댑터와 집계 API 의 코드 흐름도
31. 시뮬레이션 일괄 점검
공격 시뮬레이터 21종을 한 번에 돌려 '기대한 이벤트가 기록되는지' 확인하는 점검기와 샘플 로그 도구의 코드 흐름도

Layer 6. 부록

프로젝트 전체를 찾아보는 지도

32. 부록
프로젝트 전체를 '계층별 파일 · 기능별 테스트 · 공격별 시뮬레이터 · DB 표'로 찾아보는 파일 지도
