Project Architecture · Login Watchdog

폴더·파일이 파이프라인의 어느 단계를 맡는지 한눈에

로그인 시도가 들어온 순간부터 관리자가 잠금을 해제하는 순간까지, 요청이 어떤 파일을 거쳐 가는지와 각 파일의 역할·핵심 함수를 색으로 묶어 정리했습니다.

근거 plan.md · research.md 스택 Flask · Supabase · Slack Webhook 파일 수 25개 (핵심 16 · 선택 4 · 테스트 3 · 문서 2)
01 · 요청의 이동 경로

로그인 시도 한 건이 파일 사이를 어떻게 지나가는가

평소엔 위쪽 한 줄(정상 경로)만 돌지만, 같은 IP가 60초 안에 5회를 넘기는 순간 아래쪽 경로(SOAR 대응)가 열립니다. 점선은 해제가 다시 로그인 라우트로 돌아오는 경로입니다.
