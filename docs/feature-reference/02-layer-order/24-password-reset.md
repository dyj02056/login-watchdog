# 24. 비밀번호 찾기

<aside>
🎯 **한 줄 요약**
비밀번호를 잊은 회원이 **인증된 이메일로 재설정 링크**를 받아 스스로 새 비밀번호를 정합니다. 이전에는 관리자가 직접 처리해야 했습니다. **계정이 있는지·이메일이 인증됐는지는 어떤 응답에서도 드러나지 않습니다.**
</aside>

> 🗺️ **클릭해서 코드를 볼 수 있는 흐름도**: [24-password-reset.html](24-password-reset.html)
> 📚 **계층**: Layer 5-B. 확장 기능

---

## 🏢 비유로 먼저 이해하기

| 현실 | 이 프로젝트 |
|---|---|
| 도어락 비밀번호를 잊으면 **등록된 연락처로 임시 열쇠 전송** | 인증된 이메일로 재설정 링크 |
| 연락처가 **미등록·미확인**이면 아무 것도 안 보내지만, 안내는 **항상 똑같음** | 항상 같은 안내 |
| 열쇠는 **한 번만** 쓸 수 있음 | 1회용 토큰 |

---

## 🔄 1) 재설정 메일 요청

| 순서 | 동작 | 쉬운 설명 |
|:-:|---|---|
| ① | 봇이면 같은 안내로 종료 | 허니팟 |
| ② | **IP당 시간당 5회** + **응답 시간 5초 고정** | 한도에 걸렸을 때만 다른 문구 (IP 기준이라 가입 여부와 무관) |
| ③ | **인증된(`VERIFIED`) 이메일에만** 보냄 | 아이디가 없든 **미인증·반송**이든 아무 것도 안 하고 조용히 끝 |
| ④ | 회원별 하루 3회 한도 후 **링크(15분, 1회용)** 발송 | 6자리 코드는 **쓰지 않음** |

### 화면 응답은 항상 같습니다

| 입력 | 화면 응답 | 실제 |
|---|---|---|
| 인증된 계정 | 같은 안내 | 메일 **발송** |
| 미인증·반송·없는 아이디 | **같은 안내** | 메일 **없음** |
| 같은 IP가 1시간에 5회 초과 | "요청이 너무 많습니다" | IP 기준이라 가입 여부와 무관 |

<aside>
🔢 **왜 6자리 코드를 쓰지 않나요?**
링크를 가진 사람이 곧 **메일함 주인**이라 **기기 제한이 필요 없고**, 코드 무차별 대입이라는 **공격 면을 아예 만들지 않기** 때문입니다. (17단원의 복구는 "IP 복구"라 기기 구분이 필요해서 코드를 씁니다.)
</aside>

---

## 🔑 2) 새 비밀번호 설정

| 순서 | 동작 | 쉬운 설명 |
|:-:|---|---|
| 링크 열기 | **GET** → 입력 화면만 | 토큰을 **소비하지 않음** |
| ① | 링크가 유효한가? | 유효한 재설정 토큰이고, **회원의 이메일이 메일을 보낸 그 주소 그대로**일 때만 |
| ② | **새 비밀번호 형식을 먼저 검사** | 길이·확인칸 일치. 실패해도 **링크는 안 닳음** |
| ③ | 토큰 **1회 소비** → 비밀번호 변경 → **모든 기기 로그아웃** | 세션 세대 번호가 올라감(18단원) + 알림 메일 |

<aside>
🧾 **형식 검사를 "먼저" 하는 이유**
비밀번호 형식 실수 때문에 **링크가 닳아 버리면** 사용자는 처음부터 다시 요청해야 합니다. 형식이 통과한 뒤에만 토큰을 소비합니다.
</aside>

<aside>
🔓 **재설정은 잠금을 풀어주지 않습니다.**
비밀번호를 바꿔도 영구 잠금이 걸려 있다면 17단원의 이메일 복구로 풉니다.
</aside>

## 📍 코드는 어디에 있나요?

| 하는 일 | 파일 | 함수 |
|---|---|---|
| 화면 4개 | `routes/password.py` | `password_forgot_submit()`, `password_reset_form()`, `password_reset_submit()` |
| 인증된 이메일에만 발송 | `services/email_verification.py` | `request_password_reset()` |
| 링크 유효 확인 | `services/email_verification.py` | `get_reset_target()` |
| 1회 소비 + 비밀번호 변경 | `services/email_verification.py` | `reset_password()` |
| 응답 시간 고정 | `helpers/timing.py` | `run_with_fixed_response_time()` |
| 토큰 저장·소비 | `db/email_tokens.py` | `create_email_token()`, `consume_email_token()` |
